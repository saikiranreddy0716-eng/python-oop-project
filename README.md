# Python OOP Employee Management System

## Project Description

A Python project demonstrating Object-Oriented Programming
using an employee management system.

## Features

- Abstract Employee base class
- Developer and Manager inheritance
- Polymorphism through the work() method
- Salary validation using encapsulation
- Department and payroll management
- Composition and aggregation
- Money operator overloading
- Employee service for adding and searching employees
- Automated tests using pytest

## Requirements

- Python 3.10 or later
- pytest

## Setup

Create a virtual environment:

    python -m venv .venv

Activate it on Windows PowerShell:

    .\.venv\Scripts\Activate.ps1

Install pytest:

    python -m pip install pytest

## Run the Application

    python main.py

## Run Tests

    python -m pytest -v
